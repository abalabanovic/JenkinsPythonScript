# JenkinsPythonScript

1.Python script that interacts with Jenkins API in order to search pipelines on needed specification, in this case it is searching if the pipeline was used in last 2 years and if it is using docker in docker approaches and if its not disabled
It is reading values from xml string which are we getting as a response from API endpoint 
This script can be modified to search whatever we need 

2.Second script is for parsing output txt file to xls
